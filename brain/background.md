# Project background

MDEditorKit is a native macOS Markdown editor component built on TextKit 2. It delivers a Ulysses-style "what you see is what you mean" editing surface where Markdown source stays in place while headings, formatting, code, and links are styled inline. It powers MDWriter and is reusable in any SwiftUI or AppKit host.

## Goals
- High-performance inline Markdown styling using Apple's TextKit 2.
- Clean separation between formatting rules, layout managers, and UI views.
- Full Swift 6 concurrency and CJK typography support.
